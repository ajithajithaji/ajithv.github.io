# Ajith V — Odoo Techno-Functional Consultant Portfolio

A modern, high-performance personal portfolio built with **React + Vite**, designed to showcase my experience as an **Odoo Techno-Functional Consultant**.

The design uses a dark developer-focused interface with **signal green** and **cobalt blue** accents, subtle animations, interactive elements, and an Odoo-focused technical aesthetic.

## ✨ Features

- Modern dark developer portfolio design
- React + Vite architecture
- Responsive layout for desktop, tablet, and mobile
- Interactive cursor animation
- Smooth hover and transition effects
- Odoo-focused skills and integrations
- Experience and project showcase
- Technical workflow/deployment visualization
- Contact page with mail client integration
- CV download
- Social media links
- Query-parameter based routing
- Reduced-motion accessibility support
- Static-host compatible
- No backend required
